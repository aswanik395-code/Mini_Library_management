# Mini Library Management System

A simple Python-based Mini Library Management System that allows users to manage books, borrow and return books, check overdue books, view library statistics, and save borrowing records.

## Features

- Add new books to the library
- Search for books by title
- Borrow books
- Prevent borrowing of unavailable books
- Return books
- Automatically calculate a 7-day due date
- Detect overdue books
- View library summary
- View borrowing records
- Save borrowing records to a text file
- Menu-driven command-line interface

## Technologies Used

- Python 3
- `datetime` module
- Lists
- Dictionaries
- Functions
- Loops and conditional statements
- File handling
